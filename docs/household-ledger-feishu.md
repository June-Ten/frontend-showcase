# 家庭记账 · 飞书多维表格（单表）

只用 **一张数据表** 管家庭收支。新建多维表格后，把默认表改名为 **流水**（或直接用一张表）。

## 字段设计

| 字段名 | 飞书字段类型 | 必填 | 说明 |
|--------|--------------|------|------|
| 标题 | 文本 | 建议 | 记录标题，如「午餐」「发工资」 |
| 类型 | 单选 | 是 | `支出` / `收入`；金额始终填正数 |
| 分类 | 单选 | 是 | 见下方预置选项 |
| 成员 | 单选 | 是 | 谁花的 / 谁进的 |
| 金额 | 货币（CNY）或数字 | 是 | 单位：元，两位小数 |
| 发生日 | 日期 | 是 | 业务发生日；按月统计用此字段 |
| 备注 | 文本（多行） | 否 | |

不设「已删除」列：要作废直接删行，或自己加复选框「作废」再筛掉即可。

## 单选预置选项

**类型**：`支出`、`收入`

**成员**：`自己`、`伴侣`、`家庭公共`（按需增删）

**分类（支出）**：`餐饮`、`交通`、`居住`、`日用`、`娱乐`

**分类（收入）**：`工资`、`奖金`、`其他`

分类放在同一个「分类」单选里即可；录入时注意支出选支出类、收入选收入类。

## 推荐视图

1. **本月流水**：发生日 = 本月，按发生日倒序  
2. **支出按分类**：类型 = 支出，按分类分组并汇总金额  
3. **按成员**：按成员分组汇总  

可选公式：

- 支出金额：`IF(当前记录.类型 = "支出", 当前记录.金额, 0)`  
- 收入金额：`IF(当前记录.类型 = "收入", 当前记录.金额, 0)`  

## 示例行

| 标题 | 类型 | 分类 | 成员 | 金额 | 发生日 | 备注 |
|------|------|------|------|------|--------|------|
| 午餐 | 支出 | 餐饮 | 自己 | 36.00 | 2026-08-10 | 公司附近 |
| 地铁 | 支出 | 交通 | 自己 | 6.00 | 2026-08-10 | |
| 工资 | 收入 | 工资 | 自己 | 15000.00 | 2026-08-05 | 八月 |

## 搭建步骤

1. 飞书 → 多维表格 → 新建「我家账本」  
2. 只保留一张表，按上表建字段并配好单选选项  
3. 建「本月流水」「支出按分类」视图  

够用就行：成员、分类都用单选，不必再拆表。
